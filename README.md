# Preston & Rachel's Reception

A responsive, single-page reception website built with plain HTML, CSS, and JavaScript. No build step or package installation is required.

## Preview

Open `index.html` in a browser, or serve this folder with a static file server. For example:

```sh
ruby -run -e httpd . -p 8000
```

Then visit `http://localhost:8000`.

## Before sharing

- Replace the story and gallery placeholders with personal memories and engagement photos.
- Confirm or update the sample schedule, reception time, dress code, parking, and rain-plan details in `index.html`.
- Add a real photo-upload link when available.
- Connect the RSVP, playlist, and guestbook forms to a submission service before using them to collect responses. Currently, they only prepare text guests can copy; nothing is sent or saved.
- The countdown targets the start of September 25, 2027 in the visitor's local time; an exact reception time hasn't been provided.

The map uses the supplied address. Google Fonts and the embedded Google Map require an internet connection.
